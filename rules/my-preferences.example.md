# My preferences (example)

Copy this file to `my-preferences.md` and edit it. An AI assistant should follow it over `general.md` where they differ.

- No logo in the top banner or the bottom-left corner.
- If a banner is used, top and bottom are the same solid colour.
- Titles: a Copperplate-style face for English, a Song-style face for Chinese, no underline under Chinese.
- Never mention how long the project took or what it cost.
- End card says: COMMENT "PLAY" / I'LL SEND YOU THE LINK.
